# Testcheckliste pro Änderung

- [ ] Exakte SFM-Labels in der Welt vorhanden und verbunden.
- [ ] Maschinen akzeptieren die Items/Fluids auf den angegebenen Seiten/Slots.
- [ ] Item-IDs, Tags und Rezepttypen in JEI/EMI abgeglichen.
- [ ] AE2/Pattern Provider/Storage Bus korrekt konfiguriert.
- [ ] Bei `RETAIN` prüfen, ob Nachfuellen aus Quelle und Ziel mitspielen.
- [ ] Mehrfach-Crafts/volle Puffer testen; kein Itemverlust oder Deadlock.
- [ ] Bei Trashcan vorerst Test-Chest verwenden.
- [ ] Timings im SFM Performance-Diagramm kontrollieren.
- [ ] Erfolgreichen Test als Status im Kopfkommentar dokumentieren.
- [ ] CHANGELOG-Eintrag und Commit-Nachricht ergänzen.
